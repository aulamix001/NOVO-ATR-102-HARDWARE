# Changelog

## Download packaging — development

- Added architecture-checked VST3 ZIP packaging with installation notes, build metadata, license notices and SHA-256 manifests.
- Added a Windows build helper and Windows CI ZIP artifact generation.
- Windows builds remain unexecuted in the Linux cloud instance.

## Visual refinement — development

- Renamed the visible product, host display name, bundle and installer to ATR-102.
- Added machined knob skirts, individually lit grip flutes, domed faces and raised index markers.
- Rebuilt switches with recessed sockets, molded keycaps, side walls and pressed-state travel.
- Added smoked selector lenses, metallic trim and illuminated legends.

## 0.1.0 — development

- Introduced the native ReelGlue VST3 and standalone application.
- Added vector hardware interface, reels, VU meters, rotary controls, illuminated switches and calibration drawer.
- Added persistent host parameters, dependency resolution, linked controls and original factory settings.
- Added initial tape processing, automated DSP checks and screenshot/integration tooling.
