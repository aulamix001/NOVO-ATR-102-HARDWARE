# ATR-102 downloads

`ATR-102-0.1.0-Linux-x64-VST3.zip` contains the compiled Linux x64 development VST3. It does not run on Windows.

The Windows build workflow runs after a push to GitHub. If it succeeds, download the `ATR-102-Windows-x64-development` artifact from the repository Actions tab. Windows binaries are not included here until a Windows build succeeds.

This is a development build; see ../docs/DSP_NOTES.md for remaining modeling work.
